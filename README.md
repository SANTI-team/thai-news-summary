## 📝 2. คำอธิบายโครงงานและวิธีการทำงาน (Project Description & Methodology)

### 2.1 ปัญหาและวัตถุประสงค์
ในยุคข้อมูลข่าวสารล้นหลาม ข่าวสารภาษาไทยในแต่ละวันมีจำนวนมาก การอ่านข่าวฉบับเต็มทั้งหมดต้องใช้เวลา โครงงานนี้จึงพัฒนาขึ้นเพื่อ:
1. สรุปเนื้อหาข่าวภาษาไทยให้เหลือข้อความสั้นกระชับ 1–3 ประโยค ที่คงใจความสำคัญและข้อเท็จจริงหลักไว้อย่างครบถ้วน
2. เปรียบเทียบประสิทธิภาพระหว่าง 2 แนวทางหลัก:
   * **Extractive Summarization:** การคัดเลือกประโยคเดิมจากต้นฉบับมาใช้ (เช่น Lead-3 และ TextRank)
   * **Abstractive Summarization:** การให้โมเดล AI อ่านเนื้อข่าวแล้วเรียบเรียงเขียนบทสรุปใหม่ด้วยภาษาของตัวเอง (โมเดล **mT5** Fine-tuned)
3. สกัดและจำแนกชื่อเฉพาะ (Named Entity Recognition - NER) เช่น บุคคล สถานที่ องค์กร วันเวลา เพื่อตรวจสอบความถูกต้องและไฮไลต์เชื่อมโยงกับบทสรุป

### 2.2 ชุดข้อมูล (Dataset)
* **[ThaiSum](https://huggingface.co/datasets/pythainlp/thaisum):** คลังข้อมูลข่าวภาษาไทยพร้อมบทสรุปอ้างอิงที่เขียนโดยนักข่าว ราว 358,000 ข่าว จากสำนักข่าวชั้นนำ (ไทยรัฐ, ไทยพีบีเอส, ประชาไท, The Standard)
* ใช้ข้อมูลแบบ Streaming เพื่อประหยัดเวลาและพื้นที่จัดเก็บ โดยแบ่งเป็น:
  * **Train Set:** 5,000 ข่าว
  * **Validation Set:** 300 ข่าว
  * **Test Set:** 500 ข่าว (ชุดทดสอบมาตรฐานร่วมกันของทุกคนในทีม)

## 💬 3. ความคิดเห็นและบทวิเคราะห์โครงงาน (Comments, Insights & Discussion)

### 3.1 ความคิดเห็นต่อผลการทดลองและการทำงานของโมเดล (Performance Comments)
* **ความกระชับและความลื่นไหล:** โมเดล mT5 ที่ผ่านการเทรนสามารถสรุปใจความสำคัญของข่าวได้อย่างเป็นธรรมชาติ เรียบเรียงประโยคใหม่ได้สละสลวย แตกต่างจาก Lead-3 ที่มักได้ประโยคยาวและมีคำฟุ่มเฟือย
* **ความแม่นยำตามหมวดหมู่ข่าว:** ข่าวการเมือง ข่าวต่างประเทศ และข่าวเศรษฐกิจ ได้คะแนน ROUGE-L สูงมาก (70%–85%) เนื่องจากโครงสร้างการเขียนข่าวมีความเป็นแบบแผน (Inverted Pyramid)

### 3.2 ความคิดเห็นต่อข้อผิดพลาดและข้อจำกัด (Error Analysis & Limitations)
* **ข่าวดาราและบทสัมภาษณ์บันเทิง:** มักได้คะแนน ROUGE-L ต่ำ (ต่ำกว่า 20%) เนื่องจากเนื้อข่าวประกอบด้วยภาษาพูดและอารมณ์ความรู้สึก ทำให้นักข่าวที่เขียนสรุปอ้างอิง และโมเดล mT5 หยิบประเด็นมาสรุปคนละแง่มุม แม้ความหมายโดยรวมจะไม่ขัดแย้งกัน
* **การตกหล่นของชื่อเฉพาะรอง:** ในข่าวที่มีบุคคลหรือสถานที่เอ่ยถึงเกิน 4 รายการ โมเดลมีแนวโน้มเลือกเฉพาะชื่อประธานหลักมาสรุป ทำให้ชื่อรองตกหล่นไป

### 3.3 ความคิดเห็นและข้อเสนอแนะในการพัฒนาต่อยอด (Future Improvements)
1. **การขยายขนาดข้อมูลฝึกสอน:** หากมีทรัพยากร GPU สูงขึ้น ควรขยายชุดข้อมูลเทรนเป็น 20,000–50,000 ข่าว เพื่อเพิ่มความหลากหลายของคำศัพท์
2. **NER-Constrained Decoding:** นำเทคนิคบังคับคงชื่อเฉพาะสำคัญไว้ในระหว่างที่โมเดลกำลัง Generate คำตอบ
3. **การประยุกต์ใช้เทคนิค Parameter-Efficient Fine-Tuning (PEFT/LoRA):** เพื่อให้สามารถทดลองกับโมเดลที่มีขนาดใหญ่ขึ้น (เช่น mT5-base หรือ mT5-large) ภายใต้ข้อจำกัดของหน่วยความจำ GPU
